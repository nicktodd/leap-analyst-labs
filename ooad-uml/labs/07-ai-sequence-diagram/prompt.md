# Prompt for GitHub Copilot Chat

Paste the text below into Copilot Chat unchanged, so every pair starts from the same prompt.

```text
Draw a Mermaid sequence diagram for a retail trading platform. A client places a buy order
for 10 shares of AAPL in an Angular web app. The platform has an auth service that issues
JWTs, a Spring Boot Trade REST API, a Kafka broker, a Trade Executor service, a market data
API called Fauxnance and a Postgres database. Show the whole flow from the client clicking
Buy to the client seeing the filled order and updated position. Include error handling.
```
